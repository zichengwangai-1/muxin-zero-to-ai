# 木辛・零基础学 AI 排版与字体设计规范

## 1. 页面网格

- 最大内容宽度：1180px。
- 桌面端页面留白：左右至少20px。
- 手机端页面留白：左右14px。
- 双栏间距：48px。
- 基础间距单位：4px；常用间距为8、12、16、24、32、48和64px。
- 同一模块中的框体必须共享左右边线，同排卡片必须共享底部基线。

## 2. 卡片内部对齐

- 紧凑卡片内边距：18px。
- 图标占位轨道：48px。
- 图标与文字间距：14px。
- 标题与说明文字共用同一条左起始线。
- 图标顶部与标题区域顶部对齐。
- 同类卡片使用统一的内边距、圆角和内部栅格。

## 3. 字体层级

| 类型 | 字号 / 行高 | 用途 |
| --- | --- | --- |
| 首页主标题 | 44–72px / 1.04 | 首页核心标题 |
| 页面标题 | 38–62px / 1.10 | 求职区、目录页和文章页 |
| 模块标题 | 28–32px / 1.20 | 页面主要板块 |
| 卡片标题 | 17–20px / 1.30 | 卡片核心信息 |
| 正文 | 14–16px / 1.70 | 学习内容与解释 |
| 卡片说明 | 12–13px / 1.65 | 摘要与简短说明 |
| 标签与编号 | 10–11px / 1.50 | 编号、状态与辅助信息 |

中文正文使用系统字体与苹方；大标题保留圆润粗体。解释性文字原则上不低于12px，纯编号和状态可使用10–11px。

## 4. 圆角层级

- 14px：标签、搜索框与按钮。
- 18px：列表卡片。
- 22px：普通内容卡片。
- 30px：大型面板与主要模块。

## 5. 响应式规则

- 960px以下：主要双栏改为单栏，不强制左右模块等高。
- 640px以下：页面留白改为14px，卡片纵向排列。
- 交互控件最小高度44px，不允许水平溢出。
- 长标题允许自然换行，不通过缩小字号强行塞入一行。

## 6. 实施范围

本次只统一设计变量、框体栅格、内边距、文字起始线与字号层级；不修改内容、路由、功能、配色和卡片顺序。
