# AI 实战教学区轻量在线内容后台

## 已确认目标

用户选择手动录入、在线使用。支持六个教学模块，管理员不改代码即可补充内容。首版不做自动采集、AI 自动生成或多人审批。

## 推荐方案

采用 Decap CMS + GitHub 内容存储 + Netlify 构建发布。后台入口 `/admin/`，中文标签，通过 GitHub 登录，仅有仓库写入权限的账号可管理，不启用开放投稿。不增加数据库。与自建后台相比减少编辑器、媒体管理和草稿流程维护；与数据库方案相比保持现有静态网站与版本记录。

GitHub 仓库：`zichengwangai-1/muxin-zero-to-ai`。发布分支与 Netlify 实际连接须在实施时只读核验，不能按当前本地分支猜测。OAuth 配置需要管理员在平台完成授权；密钥仅放服务端配置，不写进浏览器或仓库。

## 录入与内容结构

- 六个模块分别有中文入口，支持新增、编辑、草稿、预览、发布及下架。
- 共用字段：稳定 ID、标题、模块内分类、简介、排序、是否展示、工具、作者、来源链接、来源日期、实测状态、封面、附件、Markdown 正文、完整 Prompt。
- 场景字段：图片参考图要求；视频成片链接；办公/开发/游戏的准备材料、步骤、结果与核对项。不要求制作难度，05/06 不要求演示入口。
- 新内容一篇一个结构化 Markdown 文件，图片和附件保存在项目媒体目录。日期未知允许留空，不把录入日期当作来源日期。
- 提供标准 Markdown 模板及 `.md` 导入控件。标准格式可解析字段并预览；普通 Markdown 作为正文导入，缺失标题或模块时提示补齐。解析不执行 HTML 或脚本，导入不会直接发布。
- 图片与附件使用受限文件类型及大小校验；视频优先填写链接，避免大型视频进入代码仓库。

## 兼容原有页面

现有 Prompt Markdown、20 个图片 JSON 案例、开发/游戏 JSON 教程目前格式不同。为它们提供对应管理配置与读取适配，不进行无损性无法证明的批量覆盖。新增统一内容与旧内容合并展示；稳定 ID 去重，未发布/下架内容不出现在列表、搜索、数量或可直接访问的详情里。

前台沿用各模块现有排版及复制按钮，适配新增内容。已有链接、图片与来源不变。后台预览展示相同关键字段，但不承诺与前台所有响应式细节完全一致。

## 保存与发布

保存草稿进入独立编辑分支，正式站点不变。发布写入经核验的发布分支，由 Netlify 自动构建。编辑器发布成功仅代表内容提交成功；构建失败时不得提示线上已更新，提供部署状态查看入口。首次上线前备份/核对本地未提交变更，禁止顺手推送其他任务修改。

下架使用显示状态，不默认物理删除内容及素材。GitHub 版本记录用于恢复。并发修改或保存失败显示错误，不静默覆盖或丢失编辑。

## 实施与外部操作边界

先完成本地后台、内容适配、导入、示例流程和测试。上线启用还需要核验 Netlify 连接、配置 OAuth、完成管理员登录授权并部署。本次不擅自创建外部账号、扩大仓库权限或发布当前所有未提交改动；需要用户操作的步骤届时明确列出。

## 验收

1. 六模块新增一篇测试草稿，前台不可见；发布后可见，下架后隐藏；使用隔离测试数据，不污染真实内容。
2. 标准 Markdown 导入及非法格式、缺字段、重复 ID 都有明确反馈。
3. 图片和附件可访问，Prompt 可完整复制，已有内容和链接不变。
4. 未授权用户不能写入；密钥不出现在静态资源中。
5. 构建与相关测试通过，实际浏览器验证后台录入、预览和前台展示。
6. 本地验证与线上 OAuth/发布验证分别报告，未接通的步骤不声称完成。
