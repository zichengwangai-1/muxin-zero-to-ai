# 木辛-零基础学AI

一个面向零基础学习者的 AI 学习网站。它不要求你先学完一整套课程，而是按真实目标整理内容：想提升办公能力、准备 AI 产品岗位，或建立对 AI 的基础理解，都可以直接从需要的板块开始。

## 在线访问

[打开木辛-零基础学AI](https://muxin-zero-to-ai.netlify.app/)

## 网站内容

### AI 产品求职区

- **00 学习路线**：转行路径、岗位认知、能力模型与准备顺序。
- **01 AI 基础知识**：大模型、机器学习、Prompt、RAG、Agent 等关键概念。
- **02 AI 产品经理核心技能**：PRD、评测、数据标注、模型选型、成本与产品运营。
- **03 应用案例拆解**：对话助手、AI 搜索、AIGC 与垂直行业产品案例。
- **04 面试题库**：概念题、产品设计题、案例题、行为题与真实面试经验。
- **05 资源导航**：书籍、课程、工具与持续学习资源。
- **06 产品体验**：值得观察的新 AI 产品，以及可用于面试的体验表达框架。
- **07 论文解读**：近期论文的核心结论、产品启发与面试表达思路。

### AI 实战教学区

正在持续开发。未来会提供办公提效、网站制作与常用 Prompt 的可复现教程。

## 本地打开网站

请先安装 [Node.js](https://nodejs.org/)，然后在项目目录运行：

```bash
npm install
npm start
```

浏览器打开：<http://127.0.0.1:5173/>

## 日常更新内容

- 文章与学习资料位于 `src/content/aipm/`。
- 面试经验资料位于 `src/data/interview-sources/`。
- 页面与交互代码位于 `src/`。

更新完成后，可以先在本地检查：

```bash
npm run build
npm test -- --run
```
