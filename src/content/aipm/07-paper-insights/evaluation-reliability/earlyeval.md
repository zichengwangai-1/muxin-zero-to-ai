# EarlyEval：Agent 任务没跑完，能否提前判断成败？

## 一句话说清

EarlyEval 尝试根据 Agent 执行到一半时的行为，提前判断任务会成功还是失败，从而减少无意义的后续步骤和 Token 消耗。

## 论文要解决什么问题

评测 Agent 很贵。传统优化常常是减少评测题目，但每道题一旦开始，Agent 仍可能运行很久。大量明显已经失败的任务还在继续调用模型和工具，既浪费成本，也拖慢团队迭代。

论文提出另一个方向：题目数量不变，但尽早结束已经能判断结果的单次运行。

## 它是怎么做的

系统从执行过程里提取行为、文本和参考方案等特征，分别训练成功预测器与失败预测器。当其中一个预测达到设定置信度，就提前停止任务。

这里的重点不是让一个大模型再评价另一个大模型，而是用较轻量的分类器做过程判断，避免“为了省成本又增加一笔很大的判断成本”。

## 关键发现

论文在 SWE-bench Verified、TerminalBench 和 Toolathlon 三个基准上测试：

- 可以减少约 13%–26% 的 Agent 执行步骤；
- 最多减少 44.1% 的输入 Token 和 29.4% 的输出 Token；
- 成败预测准确率约为 89%–97%；
- 各 Agent 的任务解决率平均只变化约 1–2 个百分点。

这些是论文实验结果，不代表所有线上业务都能获得同样收益。

## 小白怎么理解

像做一场很长的考试。如果考生前十分钟已经走进完全错误的方向，系统不用等到交卷才判断失败，可以尽早提醒重做；但也不能因为一次犹豫就判定失败，否则会错杀本来能完成的任务。

## 对 AI 产品经理的五层启发

### 1. 用户价值：失败也要尽快失败

用户不只在乎成功率，也在乎多久才能知道任务不行。对于研究、客服、数据分析等长任务，“两分钟发现失败并重试”可能比“十分钟后得到错误结果”体验更好。因此停止条件也是产品能力，不只是工程优化。

### 2. 产品机制：加入检查点，而不是只看最终答案

长任务应该设置阶段性检查，例如计划是否合理、关键数据是否拿到、工具调用是否连续报错、结果是否偏离目标。检查点通过后再投入下一阶段成本；没通过时可以重试、换模型、请求用户补充或安全退出。

### 3. 指标体系：成功率之外增加三类指标

- **有效成功率：** 真正完成用户目标且通过验收的比例；
- **失败发现时间：** 从任务开始到系统识别无法继续的时间；
- **无效消耗：** 最终失败任务在已经不可挽回后继续消耗的 Token、时间和工具费用。

还要监控误杀率：本来可以完成却被提前终止的比例。

### 4. 风险边界：便宜不能以错杀为代价

不同任务对误判的容忍度不同。生成营销文案可以积极提前停止，医疗、法律或资金操作则需要更保守的阈值。产品必须按场景设置停止策略，并允许重要任务回退到完整执行。

### 5. 产品决策：把预算分配变成动态路由

早期信号较好时，可以继续使用当前模型；信号变差时，不一定直接结束，也可以先降级任务、切换更强模型或让人接管。这样产品从“一次性调用”变成按过程证据动态投入资源。

## 如果落到真实产品

以 AI 深度研究产品为例，我会在“制定计划、收集来源、形成结论”三个阶段设置检查点：

1. 计划阶段没有覆盖用户问题，立即重新规划；
2. 来源数量足够但可信度不足，切换搜索策略；
3. 多次检索仍没有证据，明确告诉用户缺口，而不是继续生成一篇看似完整的答案。

灰度上线时先只做提示，不自动停止；确认误杀率可接受后，再对低风险任务开启自动终止。

## 面试参考答案

我最近读了 EarlyEval。它研究的不是怎样提高模型最终得分，而是能否在 Agent 执行过程中提前预测成败。论文在三个基准上减少了 13%–26% 的步骤，最多降低 44.1% 的输入 Token，同时把解决率变化控制在约一到两个百分点。

对产品经理的启发是，Agent 的体验指标不能只有最终成功率，还应该加入失败发现时间、无效消耗和误杀率。我会给长任务设置阶段检查点：如果只是暂时卡住就重试或换模型；如果关键前提已经不成立就尽早结束；高风险场景则保留完整执行和人工确认。这样既控制成本，也能让用户更快知道任务处于什么状态。

## 追问准备

### 提前停止会不会降低成功率？

会，所以要同时看节省成本和误杀率。初期可以只提示不停止，再通过真实任务校准阈值，并按任务风险设置不同策略。

### 与减少评测题目有什么区别？

减少题目是在任务之间省钱；EarlyEval 是在每个任务内部减少已经没有价值的后续执行，两者可以同时使用。

### 如何判断线上是否值得做？

先看失败任务占比、平均执行成本，以及失败是否能在早期被识别。如果多数任务很短，或失败信号直到最后才出现，收益就有限。

## 一句话记忆

**Agent 不只要做成事，还要在做不成时尽早认出来。**
