# AI 实战教学区内容

模块配置位于 `src/data/practice-content.ts`。子目录名与模块路由一致。

网站与游戏教程已接入目录与详情页。每篇使用一个文件夹，保存 `index.json`；内容包括来源日期、作者、链接、工具、成果、准备材料、步骤、完整 Prompt、验收项和验证状态。

新增教程后，在 `src/data/practice-tutorials.ts` 导入并注册。详情地址为 `/practice/:moduleId/:tutorialId`，目录与教学区卡片自动统计数量。Prompt 当前以“本站中文改编 · 尚未实测”展示，不把原作者作品当作本站改编版的实测结果。

首批仅收录来源日期在 2026-07-01 之后且原文公开 Prompt 的四篇教程。只有更新时间或缺原文 Prompt 的资料暂不注册。图片未完成核验时提供原教程配图入口，不展示未经验证的成品图。
