# 高频精华prompt库

此目录的 Markdown 文件会自动加载到 `/practice/prompts`，无需逐条修改页面代码。

首批 `精选.md` 保留用户提供的完整文档，包含 6 类、15 个 Prompt。二级标题为分类，三级标题为条目；只有包含代码块的条目才展示，结语等说明不作为分类。Prompt 内的 Markdown 标题不会被误认为分类。

新增内容可追加到 `精选.md` 对应分类，或新增 Markdown 文件（文件按名称排序）。新文件同名分类目前分别展示，建议同一分类追加到原文件。编号和括号中的数量可省略，页面自动统计真实条数。重命名文件或调整条目顺序会改变分类锚点。

格式示例（代码块内保留完整、可直接复制的正文）：

~~~~markdown
## 学习与分析

### 新的 Prompt 名称

**简介**：说明适合解决什么问题。

**使用要点**：说明需要替换的变量和准备材料。

```
我想解决的问题是：【填写问题】。
请根据以上信息……
```
~~~~

复制按钮只复制代码块正文。若一条内容包含多个代码块，会按原顺序以空行连接。添加新来源时请同时更新页面底部的来源说明（`src/components/PromptLibrary.tsx`）。
